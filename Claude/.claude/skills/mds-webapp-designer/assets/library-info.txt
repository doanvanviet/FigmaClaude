## Chart Colors (MDS Web Components v2.0 — 🌈 Chart Colors collection)
⚠️ QUAN TRỌNG — PALETTE MODE vs SINGLE HUE MODE:
  Palette mode /4: Blue/4 = PINK, Green/4 = OLIVE → SAI cho bar/donut chart thông thường
  Palette mode /1: Blue/1 = TRUE BLUE, Green/1 = TRUE GREEN → ĐÚNG cho bar/donut chart

  QUY TẮC CHỌN LEVEL:
    → Muốn màu sắc vivid, rõ ràng theo tên gọi (Blue=xanh, Green=xanh lá...) → dùng /1
    → /4 chỉ dùng khi cần màu nhạt hơn hoặc đang ở Single Hue mode

Level /1 (Palette mode) — màu vivid đúng tên:

Level /4 (Palette mode) — các màu này KHÔNG phải màu tên gọi:

Level /4 (Single Hue mode) — thực sự là màu đúng nhưng nhạt hơn:

Green/4 SingleHue: (0.47, 0.76, 0.57) = medium green ✓
→ Để dùng Single Hue: setExplicitVariableModeForCollection(chartCollection, singleHueModeId)
